# 📦 Inventario App

Aplicación web para administrar productos, precios y existencias.

## 🚀 Funcionalidades

- ➕ Registrar productos
- 📋 Consultar productos
- ✏️ Editar productos
- 🗑️ Eliminar productos
- 💰 Administrar precios
- 📊 Controlar existencias

## 🛠️ Tecnologías

- 🅰️ Angular 20
- ☕ Spring Boot
- 🐬 MySQL
- ☕ Java 21
- 🔧 Maven

## 📥 Instalación

### 1️⃣ Descargar el proyecto

### 2️⃣ Configurar la base de datos

### 3️⃣ Ejecutar el backend

### 4️⃣ Ejecutar el frontend

## ▶️ Ejecución

Frontend: `http://localhost:4200`

Backend: `http://localhost:8082`

## 🧪 Pruebas

Verifique que los productos se guarden correctamente en MySQL Workbench.

## ⚠️ Solución de problemas

Si la aplicación no funciona, revise que MySQL, Spring Boot y Angular estén ejecutándose.
